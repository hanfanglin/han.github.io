# 利润记账 · 本地记账 App

一个 iOS 风格的记账工具，用来记录每日利润。
支持字段：**用户名、成本、售价、销售额、利润**。每个用户可不定期消费，按用户名快速添加销售记录，利润自动计算。

> **数据 100% 保存在你设备本地，不上传任何服务器，断网也能用。**

## 利润怎么算

你定的公式：

> **利润 =（售价 − 成本）÷ 售价 × 销售额**

也就是先算利润率 `(售价−成本)/售价`，再乘以当次的「销售额」。添加销售时只需选用户、填销售额，利润实时显示。

## 在 iPhone 15 Pro 上「本地运行 + 本地存储」

先说一个重要事实：**iPhone 不能像电脑那样「双击一个 html 文件」就本地跑并保存数据**。苹果的安全机制规定，本地 html 文件（`file://`）在 Safari 里不允许持久存储，关掉就丢。
要在 iPhone 上「数据只存在本机、离线运行」，唯一的官方办法是：

> **用 Safari 打开一次网址 → 点「分享 → 添加到主屏幕」**，
> 装好后它就变成一个纯本地 App，数据只在这台手机里，跟服务器再无关系。

下面三种方法任选其一，都满足「本地存储、离线运行」：

### 方法 1：同一 WiFi 一次性安装（最推荐，最“本地”）
不需要任何云服务器，只在你家的 WiFi 里传一次文件：
1. 在**电脑**（Mac/PC）上进入含 `index.html` 的文件夹，运行：
   - Mac：`python3 -m http.server 8080`
   - Windows：`py -m http.server 8080`
2. 查电脑的**局域网 IP**：
   - Mac：系统设置 → 网络 → 当前 WiFi → IP 地址（形如 `192.168.x.x`）
   - Windows：命令行输入 `ipconfig` 看「IPv4 地址」
3. **iPhone** 连上同一个 WiFi，打开 **Safari**，访问 `http://<电脑IP>:8080`（例如 `http://192.168.1.20:8080`）。
4. 点 Safari 底部**「分享」⬆️ →「添加到主屏幕」→ 添加**。
5. 桌面出现「利润记账」图标，点开即全屏离线使用。**之后关掉电脑、断网都没关系，数据全在手机上。**

### 方法 2：免费静态托管（适合长期使用，零维护）
把整个文件夹上传到免费静态托管（[GitHub Pages](https://pages.github.com/) / [Vercel](https://vercel.com/) / [Netlily](https://www.netlify.com/)），得到一个网址。手机 Safari 打开该网址 → 「添加到主屏幕」。
> 安装那一下需要联网；装好后完全离线，数据只在手机本地。

### 方法 3：完全不联网、不装网址（用第三方 App）
如果你连一次性联网都不想：在 App Store 装一个能打开本地 html 的免费 App（如 **Documents by Readdle**、或 **HTML Viewer**），把 `index.html` 放进去打开。数据保存在该 App 的沙盒里，完全离线。
> 缺点：它是“在另一个 App 里打开网页”，不是桌面独立图标。

### 用微信把文件发到手机，怎么才能保存数据？
微信里直接点开 html **不能可靠保存数据**（苹果禁止本地文件持久存储，且微信内置浏览器不支持“添加到主屏幕”）。可行的两条路：
- **纯本地（推荐）**：微信收到文件 → 存到「文件」App → 用 **Documents by Readdle** 打开，数据就留在那个 App 里，离线、不联网。
- **最像原生 App**：让对方把文件发布成一个**网址**（不是文件）发你微信 → 点开选「在 Safari 打开」→ 底部「分享」→「添加到主屏幕」。装好后离线，数据只在手机。
> App 会自己检测环境：在微信里打开会弹红色提示告诉你该怎么弄；用 Safari 没装到主屏会弹蓝色引导。

## 打开 App 后会看到什么
- 顶部「今日」+ 日期，下面三张卡片：销售额 / 利润 / 订单数。
- 中间提示「还没有用户」时，去 **「用户」** 页右上角 ＋ 添加（填用户名、单位成本、单位售价）。
- 回到 **「今日」** 点右下角 **＋**，选用户、填**销售额**即可，利润自动算。
- 在 iPhone 上若还没「添加到主屏幕」，顶部会有一条蓝色引导，点它会展开安装步骤。

## 文件说明
- `index.html` —— 主程序（界面 + 逻辑 + 本地存储，**图标已内嵌，单文件即可运行**）
- `manifest.webmanifest` / `sw.js` / `icon-192.png` / `icon-512.png` —— 主屏安装与离线缓存用（可选，缺失不影响基本使用）
- 备份见「设置 → 导出 CSV / 导入 CSV 备份」

## 备份与迁移
- 「设置 → 导出 CSV」可导出全部销售记录；「导入 CSV 备份」可恢复。
- 更换设备或清浏览器数据时，请先导出 CSV。
